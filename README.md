# Xtream-Portal-Checker
Xtream Codes Portal Checker and Player

Paste or load in your xtream code lines.

Click "Check playlists" to clean your inputted data and open the playlist lists screen.

Click individual lines to check or click "Check playlists to check all".

Once a line has been checked you can view this line and play the available streams.

This plugin does not contain any playlists.

Multi language. Dark or light mode. Favourites list. EPG for channels that has the data.
